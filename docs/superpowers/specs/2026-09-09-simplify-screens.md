# פישוט המסכים — מה נשאר, מה נחתך

מעמד: הצעה לאישור, 9.9.2026 בלילה. אחרי אישור, ביצוע בשלב אחד.

## השורה התחתונה

שלושת המסכים גדלו בערימות: כל סוכן הוסיף בלוק מתחת לבלוק הקודם. הכלל
לפישוט הוא אחד — על כל מסך נשאר רק מה שמקדם את הסיפור של אותה מדרגה,
וכל השאר עובר למגירה מקופלת או למדרגה שהוא שייך אליה.

## מדרגה 3 — המלצה: משבעה בלוקים לשלושה

מה יש היום, מלמעלה למטה: פסקת פתיחה, טבלת רצועות עם כיתוב גרסה, בלוק
הלקוח שנוקד (טבלת שדות + כיתוב הסתברויות), מגירת בחירת לקוח מהטבלה, שתי
עמודות (סוכן 1 חוקים | חוות דעת שנייה עם כפתור), קונסולה, טופס פידבק,
פאנל הלומד (טבלת עיכול, מתג, כפתור, הצעה), טבלת 25 המסוכנים.

| נשאר | איך |
|---|---|
| הלקוח וההמלצה | שורה אחת: ששת השדות שהוקלדו בשורה (חוזה חודשי · סיב · בלי אבטחה · בלי תמיכה · ותק 1 · 95 לחודש), ההסתברות, הרצועה — ומתחתיה ההמלצה בתיבה ירוקה אחת עם הסיבה |
| הקונסולה | כמו היום, בלי המפריד הכפול. זו הסוכנת שמדברת על החוקים |
| טופס פידבק | מכווץ: שני הרדיו (נכון/שגוי, מה קרה) וכפתור. "פעולה טובה יותר" ו"למה" נכנסים למגירה "יש לי הצעה טובה יותר" |

| נחתך | לאן |
|---|---|
| פסקת הפתיחה על "הסתברות היא לא החלטה" | משפט אחד בכיתוב מתחת לכותרת |
| טבלת הרצועות + כיתוב הגרסה | הקונסולה כבר אומרת את שלוש הרצועות בהודעת הפתיחה. נשאר רק "חוקים גרסה 1" בכיתוב |
| עמודת "חוות דעת שנייה" עם כפתור "שאל את הסוכן" | נחתכת. זה אותו מודל שמדבר בקונסולה — שני חלונות לאותו סוכן זה בדיוק הבלבול |
| פאנל הלומד (סוכן 2) | עובר למדרגה 4 — הוא "מה המערכת למדה בפרודקשן", לא חלק מההמלצה. ראו שאלה פתוחה |
| טבלת 25 המסוכנים | נחתכת. בחירת לקוח מהטבלה נשארת במגירה "נסה לקוח אחר מהטבלה", בתחתית, עם ההסבר על ניסוח החוקים |
| שלושה מפרידים | נשאר אחד, בין ההמלצה לקונסולה |

## מדרגה 2 — חיזוי: מטבלאות ופסקאות לטבלה, טופס, שני מספרים

| נשאר | איך |
|---|---|
| טבלת הניקוד (בסיס + מודל) | כמו היום, עם משפט אחד: "הבסיס מקבל 73% בלי לתפוס אף נוטש" |
| טופס "נקד לקוח" | כמו היום |
| שני המספרים | שני האריחים והרצועה של כל אחד |

| נחתך | לאן |
|---|---|
| הדגמת הדליפה (טבלה + פסקה ארוכה) | למגירה מקופלת "למה המספר יכול לשקר — הדגמת הדליפה". נשארת לשקופית, לא על המסך כברירת מחדל |
| כיתוב "שתי משפחות, רשומה אחת" | נחתך |
| מגירת 13 השדות שמולאו מהטבלה | נשארת, אבל הכותרת מתקצרת ל"13 שדות מולאו מהטבלה" |

## מדרגה 4 — פרודקשן: הלולאה במרכז, טבלאות הביקורת במגירות

| נשאר | איך |
|---|---|
| שורת המדדים | ארבעת האריחים כמו היום |
| כפתור "נקד וכתוב" | כמו היום, המחוון לצידו |
| מספרי הלולאה | שלושת האריחים: החלטות, עם תוצאה, פסקי דין — משפט אחד מתחת |
| הלומד (סוכן 2) | עובר לכאן, מתחת למספרי הלולאה: קורא, מציע גרסה, מפרסם בלחיצה |
| היסטוריית חוקים | טבלה + שורות ההבדל בין שתי הגרסאות האחרונות |

| נחתך | לאן |
|---|---|
| פסקת הפתיחה על "הגרסה הראשונה של פרודקשן" | משפט אחד |
| טבלת החיזויים + הכיתוב הארוך | למגירה "שובל הביקורת — טבלת החיזויים" |
| טבלת הפידבקים האחרונים | למגירה "הפידבקים האחרונים" |
| הכיתובים הארוכים מתחת לכל בלוק | משפט אחד לכל היותר, או כלום |

## מה לא נוגעים בו

מדרגה 1 לא נכללה בבקשה ונשארת. הלוגיקה לא משתנה — אף פונקציה ב-`handoff`,
`rules_chat`, `learner`, `rules_store`, `data` לא נוגעים בה; זה סידור
מחדש של `app.py` בלבד, ובדיקת הרינדור של הסולם רצה אחריו.

## שאלה פתוחה אחת

הלומד (סוכן 2): במדרגה 4 כמוצע כאן, או נשאר במדרגה 3 ליד הפידבק שהוא
צורך? תסריט ההשלמה הולך ככה: פידבק במדרגה 3, השורה נוחתת בסופאבייס,
מפעילים את הלומד, החוקים עוברים לגרסה 2, אותה המלצה מתהפכת — ולכן ההצעה
היא מדרגה 4, ליד השורה שנחתה.
